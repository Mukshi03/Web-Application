# Gray Lane — Operations Dashboard

Standalone dashboard page for the Gray Lane 3PL web app. Single self-contained HTML file — no build step.

## Run it

- **Online:** https://mukshi03.github.io/Web-Application/
- **Locally:** open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000

## Data

All figures come from the `DATA` object at the top of the `<script>` in `index.html`. Replace it with a `fetch('/api/dashboard')` call when the backend is ready.
